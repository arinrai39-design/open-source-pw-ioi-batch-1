# Open Source PW IOI Batch 1

A full-stack program tracking application built as part of the Open Source PW IOI Batch 1 project.

## Tech Stack

- Next.js
- React
- TypeScript
- Node.js
- Supabase / PostgreSQL
- Turborepo
- Vercel

## Project Structure

- `apps/web-student` — Student web application
- `apps/web-admin` — Admin web application
- `apps/api-student` — Student API
- `packages/` — Shared packages and services
